# Brand Guide Setup

> **Version:** 1.0.0
> **Last Updated:** 2025-12-29

## Overview

The Brand Guide is the single source of truth for all UI styling decisions. It ensures consistency across every component, page, and interaction generated by the AI.

## Quick Start

```bash
# Create a new brand guide (interactive interview)
/hustle-brand

# Edit existing brand guide
/hustle-brand --edit

# Edit specific section
/hustle-brand --edit colors
/hustle-brand --edit voice

# View current brand
/hustle-brand --status
```

## Interview Process

### Phase 1: Foundation

Choose your setup method:

```
┌─────────────────────────────────────────────────────────────┐
│                    BRAND GUIDE CREATOR                       │
│                                                              │
│  You can either:                                             │
│  [1] Answer interview questions (recommended)                │
│  [2] Fill out a quick form (faster, uses defaults)          │
│  [3] Import from Figma/existing brand kit                   │
│                                                              │
│  Choice? >                                                   │
└─────────────────────────────────────────────────────────────┘
```

### Phase 2: Visual Identity

**Colors:**
- Primary brand color (hex or description)
- Mood for secondary colors
- Gradient preferences
- Dark mode strategy

**Typography:**
- Font family selection
- Personality (modern, classic, technical)
- Monospace for code

**Spacing:**
- Compact vs spacious
- Border radius style
- Shadow depth

### Phase 3: Motion & Animation

**Style:**
- Snappy (quick, precise)
- Smooth (gentle, flowing)
- Bouncy (playful, elastic)
- Minimal (subtle, professional)

**Library:**
- CSS transitions only
- Framer Motion
- GSAP
- None

### Phase 4: Voice & Tone

**Communication style:**
1. Professional & Informative
2. Friendly & Casual
3. Technical & Precise
4. Playful & Character-driven

**Terminology:**
- What to call users
- CTA language preferences
- Error message tone

### Phase 5: Custom Elements

Based on your answers, select custom elements:
- Terminal animations
- Gradient text
- Typing effects
- Parallax scroll
- Particle backgrounds
- Three.js scenes
- Glassmorphism
- Neumorphism

## Brand Guide Structure

### BRAND_GUIDE.md Format

```markdown
# Brand Guide

## Colors

| Name | Light Mode | Dark Mode | Usage |
|------|------------|-----------|-------|
| Primary | #ba0c2f | #d42a4c | CTAs, links, focus |
| Secondary | #1a1a1a | #e5e5e5 | Text, headers |
| Background | #ffffff | #0a0a0a | Page backgrounds |
| Muted | #f5f5f5 | #1a1a1a | Disabled states |
| Destructive | #dc2626 | #ef4444 | Errors, delete |

### Gradients

- Hero: linear-gradient(135deg, #ba0c2f 0%, #1a1a1a 100%)

## Typography

| Scale | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| xs | 0.75rem | 400 | 1rem | Captions |
| sm | 0.875rem | 400 | 1.25rem | Helper text |
| base | 1rem | 400 | 1.5rem | Body |
| lg | 1.125rem | 500 | 1.75rem | Subheadings |
| xl | 1.25rem | 600 | 1.75rem | Section titles |
| 2xl | 1.5rem | 700 | 2rem | Page titles |
| 3xl | 1.875rem | 700 | 2.25rem | Hero titles |

### Fonts

- Sans: system-ui, -apple-system, sans-serif
- Mono: ui-monospace, monospace
- Heading: (same as sans)

## Motion

| Property | Value |
|----------|-------|
| Style | Snappy |
| Library | GSAP |
| Duration Fast | 150ms |
| Duration Normal | 300ms |
| Duration Slow | 500ms |
| Easing | ease-out |

## Voice

| Property | Value |
|----------|-------|
| Tone | Technical |
| User term | developer |
| CTA style | imperative |
| Error tone | helpful |

### Do's
- Use clear, concise technical language
- Provide specific examples and code snippets
- Respect the developer's time and intelligence

### Don'ts
- Don't use marketing buzzwords
- Don't be condescending or overly simple
- Don't use emojis excessively

## Custom Elements

- [x] Terminal animations
- [x] GSAP animations
- [x] Typing effects
- [x] Grid background pattern
```

## ShadCN Integration

When the brand guide changes, ShadCN components automatically update:

```bash
# Manual sync after brand edit
/shadcn sync
```

This updates:
1. CSS variables in globals.css
2. Tailwind theme extension
3. All installed ShadCN components inherit new values

## Best Practices

### 1. Create Brand Guide Early

Run `/hustle-brand` before building any UI components. This ensures consistency from the start.

### 2. Update, Don't Replace

When updating brand colors, use `/hustle-brand --edit colors` instead of recreating the entire guide. This preserves other sections.

### 3. Reference in Components

All AI-generated components will automatically reference the brand guide:

```tsx
// Component uses CSS variables
<button className="bg-primary text-primary-foreground rounded-lg">
  Click me
</button>
```

### 4. Keep Brand Page Updated

The brand page should always reflect current brand values. Run `/shadcn sync` after major changes.

### 5. Review Periodically

```bash
/hustle-brand --status
```

Shows last update date and suggests review if >30 days old.

## Troubleshooting

### Brand not applying to components

1. Check `globals.css` has the CSS variables
2. Run `/shadcn sync` to refresh theme
3. Ensure components import from `@/components/ui/`

### Dark mode colors wrong

Edit the dark mode section specifically:
```bash
/hustle-brand --edit colors --mode dark
```

### Custom fonts not loading

1. Check font is imported in layout.tsx
2. Verify font name in globals.css `--font-sans`
